# Linux System Administration Lab

A practical 30-day Linux System Administration and Automation
portfolio project using Ubuntu Linux.

## Project Objectives

- Linux server administration
- Bash scripting and automation
- User and permission management
- SSH and firewall configuration
- Web server administration
- Ansible automation
- Docker fundamentals
- Monitoring and troubleshooting
- Backup and recovery

## Day 1 – Linux System Inventory

### Tasks Completed

- Identified Linux distribution and kernel version.
- Collected hostname and architecture information.
- Checked system uptime and load average.
- Analysed memory and swap usage.
- Checked filesystem capacity and disk usage.
- Listed block devices.

### Script

`scripts/system-inventory.sh`

### Generated Report

`logs/system-inventory-report.txt`
